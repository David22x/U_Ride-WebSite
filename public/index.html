Características

Todo lo que necesitas para viajar seguro

Verificación institucional

Solo estudiantes con correo @uta.edu.ec pueden registrarse. Cada cuenta es verificada mediante un código OTP.

Coordinación por zonas

Filtra viajes por zona o barrio. La ubicación se maneja de forma aproximada, nunca se comparten direcciones exactas.

Sistema de reputación

Califica conductores y pasajeros después de cada viaje. El promedio y el historial son visibles para toda la comunidad.

Reglas de seguridad

Cada viaje puede tener reglas visibles: puntualidad, no compartir datos personales, respeto mutuo y más.

Doble rol

Un mismo estudiante puede actuar como pasajero y como conductor. Cambia de rol con un solo clic.

Sistema de reportes

Si alguien incumple las reglas, puedes reportarlo. Los administradores revisan y aplican acciones como advertencias o suspensiones.

Cómo funciona

En tres pasos

01

Regístrate con tu correo UTA

Crea tu cuenta con tu correo institucional. Recibes un código de verificación que confirma que eres estudiante.

→
02

Busca o publica un viaje

Como pasajero filtra viajes por zona y fecha. Como conductor publica tu ruta, horario y cupos disponibles.

→
03

Viaja y califica

Solicita unirte, espera confirmación del conductor y viaja. Al finalizar, califica la experiencia.
